# ติดตั้ง AI Live บนเครื่อง GPU

เครื่อง GPU (เครื่องเดียวกับ Unsloth) จะรันสามอย่างคู่กัน:

- **LiveTalking** สร้างอวตารที่ขยับปากตามเสียงพูดภาษาไทย ใช้เสียง Edge TTS
- **SRS** ทำหน้าที่กระจายภาพ ส่งภาพอวตารไปที่จอพรีวิวใน Studio และต่อไปที่ TikTok/Facebook ตอนไลฟ์จริง
- **naka-live-agent** เป็นตัวรับคำสั่งจาก Studio เช่น เริ่ม/หยุดอวตาร สั่งพูด และเริ่มไลฟ์ ทุกคำสั่งต้องมี token

```
Studio ──token──▶ naka-live-agent :8020 ──▶ LiveTalking (127.0.0.1:8010) ──WHIP──▶ SRS (127.0.0.1:1985)
                                                                                   ├─ WebRTC :8000 ──▶ พรีวิวใน Studio
                                                                                   └─ RTMP ──ffmpeg──▶ TikTok / Facebook
```

## สิ่งที่ต้องมี

- Ubuntu 22.04 หรือ 24.04 ติดตั้งไดรเวอร์ NVIDIA แล้ว (คำสั่ง `nvidia-smi` ต้องใช้ได้)
- การ์ดจอ RTX 3060 ขึ้นไป (RTX 3090 ใช้ได้สบาย)
- พื้นที่ดิสก์ว่างประมาณ 15 GB

## ขั้นตอน

**1. คัดลอกโฟลเดอร์ `deploy/ai-live` ไปไว้บนเครื่อง GPU แล้วรันสคริปต์ติดตั้ง**

```bash
sudo bash install.sh            # ตรวจหา IP สาธารณะเอง
sudo bash install.sh 103.x.x.x  # หรือระบุ IP สาธารณะของเครื่องเอง
```

ใช้เวลาประมาณ 15–30 นาที ส่วนใหญ่เป็นการดาวน์โหลด PyTorch ถ้ามีอะไรค้างกลางทาง รันคำสั่งเดิมซ้ำได้

**2. วางไฟล์โมเดลกับอวตาร**

ไฟล์สองตัวนี้ไม่มีลิงก์ให้ดาวน์โหลดอัตโนมัติ (มีแค่บน Quark หรือ Google Drive ตามลิงก์ใน README ของ LiveTalking) ต้องโหลดเองแล้ววางตามนี้

| ไฟล์ | วางที่ |
|---|---|
| `wav2lip256.pth` (เปลี่ยนชื่อเป็น `wav2lip.pth`) | `/opt/naka-live/LiveTalking/models/wav2lip.pth` |
| `wav2lip256_avatar1.tar.gz` (แตกไฟล์ก่อน) | `/opt/naka-live/LiveTalking/data/avatars/wav2lip256_avatar1/` |

ถ้าต้องการอวตารหน้าตาของตัวเอง เปิดหน้า `avatar.html` ของ LiveTalking ใช้วิดีโอคนพูดยาวประมาณ 1 นาทีเพื่อสร้างอวตารใหม่ อวตารที่สร้างเสร็จจะไปอยู่ใน `data/avatars/` และขึ้นให้เลือกใน Studio เอง

**3. เปิดพอร์ตที่ router ให้มาที่เครื่องนี้ (port forward)**

| พอร์ต | ใช้ทำอะไร |
|---|---|
| `8020/tcp` | naka-live-agent (รับคำสั่งจาก Studio ต้องใช้ token) |
| `8000/tcp` และ `8000/udp` | ภาพและเสียงวิดีโอพรีวิว (WebRTC) |

**อย่าเปิด** พอร์ต 8010, 1985 และ 1935 ออกไปข้างนอก ทั้งสามพอร์ตใช้กันภายในเครื่องเท่านั้น

**4. เชื่อมเข้ากับ Studio**

ไปที่ Studio → **AI Live** → **ตั้งค่า** แล้วใส่ค่าต่อไปนี้

- **ที่อยู่เครื่อง:** `http://<IP สาธารณะ>:8020`
- **Token:** สคริปต์ติดตั้งแสดงให้ครั้งเดียวตอนจบ ถ้าหายดูได้ที่ `NAKA_LIVE_TOKEN` ในไฟล์ `/etc/naka-live/agent.env`
- **RTMP URL + stream key:** ไม่บังคับ ใส่เมื่อต้องการไลฟ์จริง คัดลอกจากหน้า Live Producer ของ TikTok หรือ Facebook

## การใช้การ์ดจอร่วมกับ Unsloth

การ์ดจอ 24 GB รับโมเดลวิดีโอ H3 หรือโมเดลรูป Qwen-Image พร้อมกับอวตารไม่ไหว

- ก่อนเริ่มอวตาร ให้กดปุ่ม **"ปลดโมเดล Unsloth"** ในหน้า AI Live
- agent จะไม่ยอมเริ่มอวตารถ้าหน่วยความจำการ์ดจอว่างไม่ถึง 5 GB ปรับค่านี้ได้ที่ `MIN_FREE_VRAM_MB` ในไฟล์ `/etc/naka-live/agent.env`

## คำสั่งที่ใช้บ่อย

```bash
systemctl status naka-live-agent        # สถานะตัวรับคำสั่ง
journalctl -u naka-live-agent -f        # ดู log ของตัวรับคำสั่ง
tail -f /var/log/naka-live/livetalking.log
docker logs -f naka-srs                 # log ของ SRS
sudo systemctl restart naka-live-agent  # รีสตาร์ต (อวตารและไลฟ์ที่กำลังทำงานจะหยุดด้วย)
```

## เรื่องความปลอดภัย

- **token:** ยาว 48 ตัวอักษร เก็บในไฟล์ `/etc/naka-live/agent.env` (สิทธิ์ 600) ถ้าคิดว่ามีคนรู้ token ให้แก้ค่าในไฟล์นั้นแล้วรีสตาร์ต agent
- **stream key:** เก็บไว้ในฐานข้อมูลของ Studio เท่านั้น ส่งมาที่เครื่อง GPU เฉพาะตอนกดเริ่มไลฟ์ และไม่ถูกเขียนลง log
- **SRS:** รับภาพเข้าเฉพาะจากในเครื่อง (127.0.0.1) คนข้างนอกดูพรีวิวได้ผ่าน agent ที่มี token เท่านั้น
