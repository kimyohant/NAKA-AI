# 策略文档撰写规范

通用要求：全部 Markdown；结论必须可直接执行；沿用调研文档的 Evidence / Assumption 标注；尊重活动字段（platforms / audience / goal / brandNotes / market）。

## audience_insight（受众洞察）

- **Personas**：2-3 个画像，每个含：身份/场景、核心 pains、核心 desires、购买阻碍
- **动机排序**：把「为什么买」按强度排序，指出最强的一根杠杆
- **阻碍与解法**：每条阻碍对应一个可用内容回答的方向（喂给 message_map）

## message_map（信息地图）

- **Core message**：一句话核心信息（30 字内），附 2-3 个变体（理性版/情绪版/身份认同版）
- **Proof points**：支撑核心信息的事实/卖点，每条标注来源（Evidence / Assumption）
- **Objections → Answers**：表格或列表，常见异议与一句式应答；异议从 personas 的购买阻碍推导

## campaign_plan（活动计划）

- **Channels**：从活动 platforms 字段出发，给每个渠道一句角色定位（如 tiktok=种草破圈、shopee=承接转化）
- **Creatives**：建议的创意数量与 formats 组合（与 content_brief 呼应，格式取自 ugc/product_demo/problem_solution/before_after/testimonial/unboxing）
- **Cadence**：发布节奏建议（首周/次周的频率与主题轮换）
- 不写预算具体数字；涉及预算只给方向（标注 Assumption）

## content_brief（内容简报）— 交给广告脚本 Agent 的执行规范

- **Hook 写法**：0-3 秒内必须完成「钩子」，给出 3-5 个可复用的 hook 模板（痛点质问/结果前置/身份召唤/反常识/价格冲击）
- **Formats**：列出本次要用的 formats 及各自适合的 angle
- **Do / Don't**：明确的清单（如 Do: 前 3 秒出现产品使用画面；Don't: 开头出现 logo 空镜）
- **CTA 指引**：结尾行动号召的统一写法与禁用词（来自 brandNotes）
- **产品入镜规范**：产品必须作为道具具体入镜（名称明确、外观具体），供下游资产提取为 prop
