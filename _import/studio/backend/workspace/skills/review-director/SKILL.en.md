# Product Studio Shot List Standards

## Structure (strictly per template)

- **1 beat = 1 shot** — role and seconds use exactly the values given in the request; never add/remove/merge shots
- Save everything in **one call** via `save_studio_shots` (the shot count must equal the number of beats given in the request) — an analysis that stays in your head is not saved
- Ordered as the beats; first shot is the hook (0-3 seconds), last shot is the CTA
- Template `asmr_closeup` has no dialogue in any shot (dialogue = null) — macro visuals and natural product sound only
- Template `lifestyle_showcase`: the final packshot shot uses a short voice-over pointing to the product

## dialogue — it must fit the time

- **en/id/vi/ms/fil/es/pt**: ~2.5 words/second → a 5-second shot ≈ 12 words
- **th/zh/ja/ko**: ~4-5 written characters/second (a Thai syllable ≈ 3 written characters)
- Over-length dialogue is an immediate failure — cut to the core sentence first
- Language = project.language only; never mix another language in

## Market adaptation

- Currency/price format: TH=THB, SG=S$, MY=RM, ID=Rp, VN=₫, PH=₱, US/UK/EU/JP/KR/CN standard symbols, LATAM/MENA default USD
- Audience address and humor fit that market's culture (e.g. TH polite particles "ค่ะ/ครับ" matching the avatar's voice)
- Platform tone: tiktok_shop/shopee/lazada → live-selling urgency · instagram_reels → polished, aesthetic · youtube_shorts → clear demonstration

## Compliance (never cross — platform review will reject these)

1. No medical/therapeutic claims, no "cures", no unverifiable results ("100%", "guaranteed")
2. Never claim to be a "real customer" or "real review" — creator_story stays in a creator's voice
3. No competitor brand names (comparison template says "the generic one / typical products")
4. Prices/promotions only from user-provided notes/instruction — if none given, do not mention price

## Writing visuals

- What the camera actually sees: the viewer can picture it instantly (who, doing what, where, where the product is)
- With an avatar → on-screen characters must match the avatar description
- No camera language in visuals ("she picks up the bottle and shows the back", not "camera zooms in")
