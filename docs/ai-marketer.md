# นักการตลาด AI — สตูดิโอ 05 (`/studio/marketer/`)

ต้นแบบจาก TopView AI Marketer (topview.ai/ai-marketer) ปรับให้ร้านออนไลน์ไทย: TikTok Shop · Shopee · Lazada · Facebook/IG · LINE OA
หลักเดียวกับต้นแบบ: **ทุกทางเข้าจบที่ "งาน" ให้ AI ทำ** แต่ละงานใช้ 1 เครดิต (คืนอัตโนมัติถ้าไม่สำเร็จ)

## หน้าตาและ flow

| ส่วน | ทำอะไร | หลังบ้าน |
|---|---|---|
| กล่องสั่งงาน + ชิป 4 กลุ่ม (วิเคราะห์ตลาด / หน้าร้านและรีวิว / คอนเทนต์และครีเอเตอร์ / โฆษณาและผลลัพธ์) | ชิปเติมแม่แบบที่มี [ช่องว่าง] ให้แก้ · เลือก "ผู้เชี่ยวชาญ" ตามแพลตฟอร์ม และหมวดสินค้า | `POST /api/marketer/tasks/insight` |
| 01 วิเคราะห์การตลาด (Marketing Insight) | สุ่มหัวข้อแนะนำ 6 จาก 12 แม่แบบ → รายงาน: สรุป หัวข้อ สิ่งที่ต้องทำ (พร้อมช่วงเวลา) ข้อควรระวัง | job `marketer_insight` · ใช้คลิปมาแรงในหมวดนั้นเป็นข้อมูลอ้างอิง |
| 02 ลิงก์สินค้า → คลิป (URL to Video) | วางลิงก์ → อ่านชื่อ ราคา รูป (Open Graph / JSON-LD) → แก้ข้อมูล → ส่งต่อไป `/review/` ทำคลิปรีวิวพร้อมเสียงพากย์ (1 เครดิตที่หน้านั้น) | `POST /api/marketer/product` · รูปผ่าน `GET /api/marketer/image` ที่เซ็นลายเซ็นแล้วเท่านั้น |
| 03 ทำซ้ำคลิปไวรัล (Recreate Viral Ads) | 2 โหมด (ทำโครงซ้ำ / เปลี่ยนองค์ประกอบ) · อัปโหลดคลิป → เบราว์เซอร์แยกภาพนิ่ง 8 ภาพ (คลิปไม่ออกจากเครื่อง) หรือกด "ทำซ้ำ" จากคลิปมาแรง → ถอดสูตร + บทคลิปใหม่ช็อตต่อช็อต | job `marketer_recreate` (Claude vision) |
| 04 สร้างโฆษณาหลายแบบ (Bulk Create Ads) | บรีฟเดียว 1–10 แผน ต่างมุมขาย · ช่องทาง ความยาว 15/30/60 วิ น้ำเสียง → แต่ละแผนกด "ทำเป็นคลิปรีวิว" | job `marketer_bulk` |
| งานของฉัน | 20 งานล่าสุด สถานะ และเปิดดูผลซ้ำได้ | `GET /api/marketer/tasks` |
| คลิปมาแรง พร้อมทำซ้ำ | ประเทศไทย · กรองหมวด (14 หมวดแบบ TikTok Shop) ยอดวิว ช่วงเวลา · เรียงตามยอดวิว/ยอดขาย/เอนเกจเมนต์/ใหม่ | `GET /api/marketer/trending` (สาธารณะ แคช 2 นาที) |

AI: `claude-opus-5-5` + structured outputs (JSON schema) + fallbacks · system prompt มีบริบทตลาดไทย (เลขเบิ้ล วันเงินเดือนออก เทศกาล กฎ อย./สคบ.) และห้ามแต่งตัวเลขยอดขาย

## ข้อมูลคลิปมาแรง — 2 ทาง (ใช้พร้อมกันได้)

1. **คัดเอง / นำเข้าไฟล์** — `/admin/system/` แท็บ "คลิปมาแรง"
   - เพิ่มทีละคลิป: วางลิงก์ TikTok → ดึงชื่อและภาพปกจาก TikTok oEmbed ให้เอง
   - นำเข้า CSV/JSON ที่ export จาก FastMoss / Kalodata (≤1,000 แถว) อ่านชื่อคอลัมน์ทั่วไปให้อัตโนมัติ (video url, views/play count, revenue/GMV, likes, category, title …) · ถ้ายอดขายเป็นดอลลาร์ ให้ใส่อัตราแลกเปลี่ยน
2. **API อัตโนมัติ** — ตั้ง `TRENDING_API_URL` + `TRENDING_API_KEY` (+ `TRENDING_API_USD_RATE` ถ้าเป็นดอลลาร์) ในแท็บ API และการเชื่อมต่อ
   - cron ดึงทุกชั่วโมง (นาทีที่ 7) หรือกด "ดึงจาก API ตอนนี้"
   - รูปแบบ: `GET <url>` + `Authorization: Bearer <key>` ตอบ JSON array หรือ `{ data | list | items | videos | results: [...] }` ใช้ชื่อฟิลด์เดียวกับไฟล์นำเข้า
   - FastMoss และ Kalodata เปิด API เฉพาะแผน Enterprise (ไม่มีเอกสารสาธารณะ) — เมื่อได้ API จริง ถ้าชื่อฟิลด์ต่างจากที่รองรับ ให้ทำ proxy เล็ก ๆ แปลงรูปแบบ หรือเพิ่มชื่อฟิลด์ใน `normalizeTrending()` (`src/marketer/trending.ts`)
- ภาพปก TikTok หมดอายุ cron จึงรีเฟรชวันละครั้ง (ครั้งละ 3 คลิป) · คลิปที่ปิด "แสดง" ไม่ขึ้นหน้าลูกค้า · นำเข้าซ้ำอัปเดตแค่ตัวเลข ไม่ทับหมวดหรือสถานะที่แอดมินตั้ง

## วิดีโอ AI (สร้างคลิปใหม่จริง แบบ TopView) — `src/video/`

ปุ่ม "🎬 สร้างวิดีโอ AI" อยู่ในผลงาน "ทำซ้ำคลิปไวรัล" / "สร้างโฆษณาหลายแบบ" และในขั้น "ลิงก์สินค้า → คลิป"

| โหมด | ส่งให้โมเดลวิดีโอ |
|---|---|
| ทำโครงซ้ำ (`recreate`) | คลิปต้นแบบ (reference video) + รูปสินค้า + แผนช็อตจาก AI → คลิปใหม่ตามโครงเดิม |
| เปลี่ยนคน / สินค้า (`replace`) | คลิปต้นแบบ + รูปคน (ยินยอมแล้ว หรือใบหน้า AI) และ/หรือรูปสินค้า → คงฉากและท่าทาง เปลี่ยนเฉพาะสิ่งที่เลือก |
| จากแผนช็อต (`plan`) | รูปสินค้า (+ รูปพรีเซนเตอร์) + แผนช็อต → คลิปโฆษณาใหม่ |

- ไฟล์ของผู้ใช้ขึ้น R2 ที่ `marketer/<userId>/…` (คลิป ≤50 MB, รูป ≤10 MB, ตรวจ magic bytes) · ผู้ให้บริการดึงผ่านลิงก์ที่เซ็นลายเซ็น อายุ 6 ชั่วโมง
- รูปคนต้องติ๊กยืนยัน "ยินยอม" หรือ "ใบหน้า AI" ตอนอัปโหลด (บันทึก `person` + `consent_at` ใน `marketer_media`)
- งานเป็น job `ai_video` ถือเครดิต `AI_VIDEO_CREDITS` (ค่าเริ่มต้น 5): ส่งครั้งเดียว → cron ดูผลทุก ~30 วินาทีด้วย `JobDeferredError` (ไม่เปลือง retry) → เก็บผลลง R2 → หน้า "วิดีโอ AI ของฉัน" เล่น/ดาวน์โหลด
- ล้มเหลว / ผู้ให้บริการปฏิเสธ / ไม่รู้ว่าส่งถึงหรือไม่ / เกิน 45 นาที → คืนเครดิต และ**ไม่ส่งซ้ำ** (กันโดนคิดเงินสองครั้ง)
- ตั้งค่าในหลังร้าน แท็บ API และการเชื่อมต่อ → "วิดีโอ AI": ผู้ให้บริการ, คีย์, Base URL, รุ่นโมเดล, ความละเอียด

### สถานะตัวเชื่อมผู้ให้บริการ (ยังไม่มี)

โครง (`src/video/provider.ts`) พร้อมแล้ว แต่ **ยังไม่มีโมดูลผู้ให้บริการที่ลงทะเบียน** — ตั้ง `VIDEO_PROVIDER` เป็น seedance/wan/minimax ตอนนี้จะขึ้น "ยังไม่ได้ติดตั้งตัวเชื่อมผู้ให้บริการวิดีโอนี้"
ทางเลือก: (ก) คัดลอก adapter จาก naka-drama-studio (CC BY-NC-SA 4.0 — ใช้ได้เฉพาะไม่เชิงพาณิชย์ ต้องมี LICENSE + NOTICE ในโฟลเดอร์ `src/video/providers/`) หรือ (ข) เขียนใหม่จากเอกสาร API ทางการ — แต่ละตัวแค่ implement `submit` / `poll` แล้ว `registerVideoProvider(...)`
