# การวิเคราะห์โฆษณาอ้างอิง (Recreate Viral Ad)

## หลักการสำคัญ

1. **แหล่งข้อมูลเดียวคือ transcript ที่ผู้ใช้วาง** — backend ไม่ดึงวิดีโอจาก TikTok/IG/YouTube สิ่งที่ transcript ไม่มี = ไม่รู้ ให้เขียนกำกับว่าไม่พบข้อมูล **ห้ามเดาหรือแต่งเติม**
2. **ห้ามลอกถ้อยคำต้นฉบับเกิน 1 ประโยค** — สิ่งที่วิเคราะห์คือ "โครง" (โครงสร้าง beat จังหวะ กลยุทธ์) ไม่ใช่ข้อความ ตัวอย่างประโยคต้นฉบับอ้างได้ไม่เกิน 1 ประโยคเท่านั้น
3. ชื่อแบรนด์/คู่แข่งจากต้นฉบับ **ห้ามปรากฏ** ใน analysis ให้เรียกว่า "สินค้าต้นฉบับ" หรือ "ผู้พูด"

## หัวข้อบังคับ (เรียงตามนี้ ชื่อหัวข้อต้องตรงเป๊ะ)

```
## Hook (0–3s)
ประเภท hook (pain question / result first / counter-intuitive / price shock / identity call ฯลฯ)
+ สรุปว่า 3 วินาทีแรกใช้ถ้อยคำ/ภาพแบบไหน (เรียบเรียงใหม่)

## Structure
ตาราง: เวลา | beat (hook/problem/demo/proof/offer/CTA) | สิ่งที่เกิดขึ้น (ภาพ + เสียงพูด)
- ไม่รู้เวลาแน่ชัดให้ประมาณและกำกับว่า "ประมาณ"
- beat ไหนไม่มีในต้นฉบับให้ข้าม

## Pacing & Format
ความยาวรวมโดยประมาณ · จำนวนช็อต/ฉากโดยประมาณ · UGC หรือสตูดิโอ · มีคนพูดกล้องไหม · จังหวะตัดเร็ว/ช้า

## Persuasion Levers
เหตุผลที่โฆษณาได้ผล (social proof / scarcity / before-after / authority / price anchor ฯลฯ)
- อ้างเฉพาะที่ transcript รองรับ — ไม่พบให้เขียนว่า "transcript ไม่ได้ให้ข้อมูลส่วนนี้ สรุปไม่ได้"

## CTA
รูปแบบ CTA (สั่งซื้อเดี๋ยวนี้ / กดตะกร้า / ติดตาม ฯลฯ) — เรียบเรียงใหม่

## Reuse Template
โครงแบบเติมคำ (placeholder) ใช้กับสินค้าอื่นได้ทันที เช่น
- Hook: [คำถาม/ข้อเสนอ 3 วินาทีแรกเกี่ยวกับ <ปัญหาหลักของสินค้าเรา>]
- Beat 2: [แสดงปัญหา] → Beat 3: [สาธิตสินค้า] → ... → CTA: [คำสั่งปิดท้าย]
```

## สิ่งที่ต้องไม่ทำ

- ไม่เดาตัวเลขยอดวิว/ยอดขาย/ราคา ถ้าผู้ใช้ไม่เขียนใน notes
- ไม่ใส่ความเห็นเรื่องแบรนด์ต้นฉบับในเชิงชมเชยจนกลายเป็นการลอกโทนข้อความ
- ไม่ข้ามการเรียก `save_reference_analysis` — วิเคราะห์ในหัวต้องถูกบันทึกลง DB
