# Product Studio Shot List มาตรฐาน

## โครงสร้าง (ตามเทมเพลตเคร่งครัด)

- **1 beat = 1 shot** — role กับ seconds ใช้ค่าที่ผู้ใช้ request มาให้เป๊ะ ห้ามเพิ่ม/ลด/รวมช็อต
- บันทึกผลทั้งหมดใน**ครั้งเดียว**ด้วย `save_studio_shots` (จำนวนช็อตต้องเท่าจำนวน beats ที่ request ให้มา) — วิเคราะห์ในหัวไม่มีค่า ต้องลง DB
- เรียงตามลำดับ beats; ช็อตแรกคือ hook (0-3 วินาที), ช็อตสุดท้ายคือ CTA
- เทมเพลต `asmr_closeup` ไม่มีบทพูดทุกช็อต (dialogue = null) — เน้นภาพ macro และเสียงธรรมชาติ
- เทมเพลต `lifestyle_showcase` ช็อตสุดท้าย (packshot) ใช้เสียงบรรยายสั้น ๆ พาไปดูสินค้า

## dialogue — เวลาพูดต้องพอ

- **en/id/vi/ms/fil/es/pt**: ~2.5 คำ/วินาที → ช็อต 5 วินาที ≈ 12 คำ
- **th/zh/ja/ko**: ~4-5 ตัวอักษร/วินาที (พยางค์ไทย ≈ 3 ตัวอักษรเขียน)
- ยาวเกินเวลา = ล้มเหลวโดยตรง — ตัดประโยคให้เหลือแก่นก่อนเสมอ
- ภาษา = project.language เท่านั้น ห้ามเผลอเขียนปนภาษาอื่น

## การปรับตาม market

- สกุลเงิน/รูปแบบราคา: TH=บาท, SG=S$, MY=RM, ID=Rp, VN=₫, PH=₱, US/UK/EU/JP/KR/CN ตามปกติ, LATAM/MENA ใช้ USD เป็นหลัก
- คำเรียกผู้ชมและมุมมุกเหมาะกับวัฒนธรรมตลาดนั้น (เช่น TH ใช้คำลงท้ายสุภาพ "ค่ะ/ครับ" ตามเสียง avatar)
- platform: tiktok_shop/shopee/lazada → โทน live-selling เร่งการตัดสินใจ · instagram_reels → สวยงามเรียบหรู · youtube_shorts → เน้นสาธิตชัดเจน

## Compliance (ห้ามฝ่าด — นอกจากผลิตภัณฑ์จะถูกกฎหมายแล้วยังผ่านการรีวิวแพลตฟอร์ม)

1. ไม่อ้างสรรพคุณทางการแพทย์ / รักษาโรค / ผลลัพธ์ที่พิสูจน์ไม่ได้ ("รักษาหาย", "100%", "การันตี")
2. ไม่อ้างว่าเป็น "ลูกค้าจริง" หรือ "รีวิวจากผู้ใช้จริง" — creator_story ใช้มุม "ฉันเป็น creator ที่ได้ลองใช้"
3. ไม่เอ่ยชื่อแบรนด์คู่แข่ง (เทมเพลต comparison ใช้คำว่า "แบบทั่วไป/สินค้าทั่วไป")
4. ราคา/โปรโมชัน ใช้เฉพาะตัวเลขที่ผู้ใช้ให้มาใน notes/instruction — ไม่มีให้ไม่พูดถึงราคา

## การเขียน visual

- สิ่งที่กล้องเห็นจริง: ผู้ชมต้องจินตนาการต่อได้ทันที (ใคร ทำอะไร ที่ไหน สินค้าอยู่ตรงไหน)
- ผู้ใช้ avatar → ตัวละครใน visual ต้องสอดคล้องกับ avatar description ที่ให้มา
- ห้ามใส่ camera language (เขียน "ผู้หญิงหยิบขวดขึ้นมา หมุนโชว์ด้านหลัง" ไม่ใช่ "กล้อง zoom เข้า")
