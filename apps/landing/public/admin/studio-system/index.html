CONTROL ROOM

ระบบ naka-studio

เวอร์ชัน พื้นที่จัดเก็บ และคิววิดีโอของ studio ดูและยกเลิกงานที่ค้างได้จากที่นี่

ยังดึงข้อมูลจาก naka-studio ไม่ได้

ตั้ง "ที่อยู่ภายในของ naka-studio" (เช่น http://studio:5679 ใน Docker) และ "โทเคนแอดมินของ naka-studio" (ค่าเดียวกับ ADMIN_TOKEN ของ studio) ได้ที่ ตั้งค่าระบบ → API และการเชื่อมต่อ

คิววิดีโอ

แต่ละ provider ทำได้ตามจำนวนงานพร้อมกันที่ตั้งไว้ งานสถานะ "ไม่ทราบผล" ยึดช่องคิวไว้จนกว่าจะยกเลิก (เช่น เมื่อเซิร์ฟเวอร์ AI รีสตาร์ตกลางงาน)

พื้นที่จัดเก็บ

เวอร์ชันและการอัปเดต

อัปเดต studio บนเซิร์ฟเวอร์ (โฟลเดอร์ที่ deploy ไว้):

git pull
docker compose up -d --build studio

ข้อมูลและไฟล์อยู่ใน PostgreSQL และ Docker volume จึงไม่หายตอนอัปเดต ควร pg_dump ก่อนอัปเดตที่มี migration
