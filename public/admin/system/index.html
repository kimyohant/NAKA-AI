CONTROL ROOM

ตั้งค่าระบบ naka-ai

เปิด/ปิดฟีเจอร์ ใส่ API key และแก้แพ็กเกจได้จากที่นี่ มีผลภายในไม่กี่วินาทีโดยไม่ต้อง deploy

ยังไม่ได้ตั้งกุญแจเข้ารหัส (SETTINGS_KEY)

ค่าทั่วไปและสวิตช์ฟีเจอร์บันทึกได้แล้ว แต่ API key ต้องมีกุญแจนี้ก่อน รันคำสั่งนี้ในโฟลเดอร์โปรเจกต์ครั้งเดียว แล้วโหลดหน้านี้ใหม่:

node -e "console.log(require('crypto').randomBytes(32).toString('base64'))" | npx wrangler secret put SETTINGS_KEY

เก็บกุญแจนี้ไว้ ถ้าเปลี่ยนหรือลบ API key ที่บันทึกไว้จะอ่านไม่ได้และต้องใส่ใหม่

ย้ายค่าจาก Cloudflare

คัดลอกค่าที่ตั้งไว้ด้วย wrangler (vars/secrets) เข้ามาเก็บในระบบนี้ ค่าที่ตั้งจากหน้านี้แล้วจะไม่ถูกทับ

ค่าที่แก้ได้เฉพาะใน Cloudflare

กุญแจหลักของระบบ แก้ด้วย npx wrangler secret put หรือ wrangler.jsonc เพื่อไม่ให้หน้าเว็บถือกุญแจของตัวเอง

    ราคาใหม่มีผลกับการซื้อครั้งถัดไป ลูกค้าที่จ่ายแล้วได้ตามที่จ่าย · หยุดขาย = ซ่อนจากหน้าราคาและหน้าชำระเงิน แต่ลูกค้าเดิมยังใช้ต่อได้ · รายปีคิด 10 เดือน
